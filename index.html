MAVREC scene 1: Stage 1 re-rendering

What we did

Stage 1 needs to re-render a drone clip from a new camera angle, so a model can later learn how a tracked object's box should move when the camera changes. Part 1 uses ReCamMaster to do the re-rendering. Part 2 uses TrajectoryCrafter for the same task. TrajectoryCrafter estimates depth and reprojects the real scene, then uses diffusion only to fill small gaps, so it stays closer to the real footage.
